# ADR 0001: Phase 0 package foundation

## Status

Accepted for the pre-alpha foundation.

## Decisions

- Identity: FastAPI Infra; distribution `fastapi-infra`; import `fastapi_infra`; repository `Talhaahmad9/fastapi-infra`.
- The project is public, independent, open source, and MIT licensed; it is not affiliated with or endorsed by FastAPI.
- Python 3.12 is the minimum without an upper bound; CI covers 3.12, 3.13, and 3.14, with 3.14 as the local development version.
- uv manages the project and lockfile; `uv_build` builds it; Ruff formats and lints; Pyright is the sole strict type checker; pytest runs tests.
- Runtime code never reads environment variables or `.env` files. Consuming applications load environments and pass validated, typed configuration to runtime components.
- PostgreSQL/Supabase is the first planned database integration; MongoDB Atlas/PyMongo Async is second.
- The project will not use Supabase Auth; authentication remains application-owned.
- Opaque server-side cookie sessions are planned.
- No initial Next.js frontend is planned.
- An isolated reference application is planned inside the repository but excluded from package artifacts.
- Testing will be layered: focused unit tests, integration tests, and later security/system gates as behavior exists.
- A generator is deferred.
- External services will be created only when their milestone begins.
- Production readiness will not be claimed before security and integration gates pass.

## Deliberately deferred

Optional dependency names; exact password-policy parameters; the compromised-password source; CSRF representation; session metadata and retention; email retry/outbox behavior; shared SQL/Mongo contracts; Redis; the Next.js consumer; generator design; and Python 3.15 support.
